## Bioinformatics

<p align="justify">
<strong>Sequence processing and quality control:</strong> Bash and <code>awk</code> for text and FASTA processing; familiarity with FASTA, FASTQ, and SAM/BAM formats, FastQC, MultiQC, SeqKit, and Samtools.
</p>

<p align="justify">
<strong>Read alignment:</strong> Currently learning about <a href="https://bio-bwa.sourceforge.net/bwa.shtml">BWA</a> for mapping sequencing reads to a reference genome. This is a learning area, not a claim of professional experience.
</p>

<p align="justify">
<strong>Variant data:</strong> Project work with <a href="https://www.htslib.org/doc/bcftools.html">bcftools</a> for VCF filtering and <a href="https://github.com/nf-osi/mafsmith">mafsmith</a> for VCF-to-MAF conversion. Currently learning about <a href="https://vcftools.github.io/man_latest.html">VCFtools</a> for VCF filtering and summary statistics.
</p>

<p align="justify">
<strong>Workflows and data sources:</strong> Basic Snakemake knowledge; training in whole-genome and bulk RNA sequencing; exploratory work with TCGA-LUAD and UniProt data; familiarity with public resources such as NCBI, Ensembl, ClinVar, and gnomAD.
</p>

Soy Ingeniero Biológico de la Universidad Nacional de Colombia, sede Medellín, con formación en biotecnología, microbiología y análisis de datos biológicos. Desarrollo proyectos de aprendizaje que combinan programación y herramientas computacionales para explorar datos genómicos, analizar secuencias y visualizar información. Busco oportunidades junior en bioinformática, análisis de datos biológicos o biotecnología.

## 🔬 Bioinformática

- Análisis de secuencias y trabajo con formatos FASTA, FASTQ, SAM y BAM.
- Familiaridad de formación con FastQC, MultiQC, Samtools y SeqKit.
- Exploración de datos públicos de TCGA-LUAD y UniProt; consulta de recursos como NCBI, Ensembl, ClinVar y gnomAD.
- Flujo exploratorio VCF-to-MAF con `bcftools` y `mafsmith`; conocimientos básicos de Snakemake.

## 📌 Proyectos destacados

- [Cancer Genomics Analysis Workflows](https://github.com/NSTRvG/cancer-genomics-analysis-workflows): proyecto de aprendizaje sobre datos de TCGA-LUAD y un flujo técnico VCF-to-MAF. No es una herramienta clínica.
- [BioProcess Signal Explorer](https://github.com/NSTRvG/-bioprocess-signal-explorer): aplicación exploratoria para analizar y visualizar series temporales de bioprocesos con datos sintéticos y una muestra de IndPenSim.
- [Sequence Analyzer](https://github.com/NSTRvG/Sequence-Analyzer): análisis de secuencias FASTA con Bash y `awk`.
- [BifidoProteomeAnalyzer](https://github.com/NSTRvG/BifidoProteomeAnalyzer): análisis y visualización de datos de proteínas de *Bifidobacterium* obtenidos de UniProt.

## 💻 Herramientas

**Programación y datos:** Python (Pandas, NumPy), SQL básico, Bash, Linux y `awk`.  
**Visualización:** Matplotlib, Seaborn, Streamlit y Plotly.  
**Flujos y reproducibilidad:** Git, GitHub, Conda y Snakemake básico.
